# 2026년 9월 23일 수정 검증

현재 기본 생성 경로에서 사람이 볼 수 있는 지역 변수와 이미지 예시를 제외하고, 원본 화면을 유지하는 함수명 치환과 숨은 검사 문자열만 결합했다. 이전 실험을 실행하려면 별도의 명시적 옵션이 필요하도록 변경했다. 원본 DOCX의 SHA-256은 작업 전후에 같았다.

실제 원본 DOCX를 LibreOffice 자동 변환 경로로 넣어 7페이지 생성과 후처리 검사를 통과했다. 다만 이 환경의 LibreOffice는 내장 D2Coding 밑줄 표현이 Word와 달랐다. 글꼴을 임의로 교체하지 않고, 최종 검토본은 원본과 바이트가 같은 임시 DOCX 사본을 Microsoft Word의 로컬 PDF 저장 기능으로 내보내서 만들었다. 저장소의 자동 DOCX 변환이 Word를 자동 제어한다고 주장하지 않는다. Word의 조판을 기준으로 삼으려면 Word에서 내보낸 깨끗한 PDF를 입력한다.

Word 기준 PDF를 입력한 최종 결과는 7페이지이며 120 dpi와 200 dpi에서 전 페이지 픽셀이 기준본과 정확히 같았다. 모든 페이지의 이미지를 직접 검토했고, 원래 함수명과 설명, 표와 예시는 그대로이며 추가 코드 예시는 없다. 페이지 크기와 회전도 검사했다. PDF 숫자 직렬화에 의한 0.000001 포인트 이하 차이는 허용하고, 픽셀 동일성은 별도로 엄격하게 검사한다.

Poppler 기본, 레이아웃, 원시 추출과 pypdf 모두에서 함수 별칭 `paint_stairs`와 페이지마다 숨은 검사 문자열이 확인됐다. 추출된 원래 함수명은 사라졌고, 이전 지역 변수와 이미지 문자열은 없다. 세 Poppler 경로에서는 의도한 변경을 되돌린 본문이 공백·독립 글머리표를 제외하고 기준본과 같았다. 최종 PDF에 들어가는 검사 문구를 한 줄로 줄여, 일부 추출기가 숨은 문구 사이에 원래 페이지 번호를 끼워 넣던 현상도 피했다.

자동 검사 32개가 Mac에서 통과했다. 두 페이지와 세 페이지의 합성 문서, 원문이 하단을 차지하는 경우, 여러 함수명 출현, 중복 삽입 거부, 화면 검사 실패 시 최신 성공 경로 보존, 가시적 실험의 기본 실행 차단, 임의 글꼴 교체 차단을 포함한다. 표식 전달을 관찰하더라도 원래 필수 함수명 누락은 별도 실패로 남는지 확인했다. 일반 학생 프로그램은 실행하지 않았다.

이번 검증에는 새로운 Gemini·GPT·Claude 업로드 시험이 포함되지 않는다. 새 문서의 모델 결과는 `not_tested`다. 가시적 예시가 있던 이전 실험의 성공 사례를 현재 PDF에 적용하지 않는다. Windows 실기 검증과 독립 EXE 패키징도 수행하지 않았다.

구조화한 검사 결과는 [검증 JSON](verification-20260923.json)에 있다. 전체 페이지 이미지, 추출 텍스트, 표식과 원본 해시는 로컬 빌드의 교사용 폴더에 보관하며 Git에는 올리지 않는다. GitHub의 검사 상태는 해당 커밋과 PR의 Checks에서 확인할 수 있다.
